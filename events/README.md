# UPAD Events

Interactive event pages for the Uttar Pradesh Association of Detroit (UPAD).

This directory contains web pages and supporting assets for UPAD events.

## Structure

Events are organized by year and event name.

Example:

2026/
- diwali/
- holi/
- picnic/
- kavi-sammelan/

Each event directory may contain:
- `index.html` — event webpage
- `assets/` — images, logos, QR codes and other event assets
